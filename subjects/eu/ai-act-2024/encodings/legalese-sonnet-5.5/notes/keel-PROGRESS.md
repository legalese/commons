## Build method

Sources with quote placeholders are in `../../work/src/<name>.l4.in` (lines `--@Q N-M` for the consolidated text, `--@QB N-M` for the as-enacted base text, `--@QO N-M` for the Omnibus); `python3 -I ../../work/build.py <name>` expands them with `srcrefs.py quote` and `quoteid`.
`../../work/tracecheck.py FILE OUT...` compares each `-- EXPECT FULFILLED|BREACH` comment with the trace result that `l4 run` printed.
