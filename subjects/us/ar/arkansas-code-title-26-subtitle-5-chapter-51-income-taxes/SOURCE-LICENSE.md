Public.Resource.Org, 590 U.S. 255 (2020) is directly in point for the annotations of a state code produced by a publisher under a legislature's supervision - it held the annotations there uncopyrightable too. Ark. Code Ann. s 1-2-123 ('Official printed version of Code - Official electronic version of Code - Printed version to take precedence', seen in the register's table of contents) is the provision that designates the official versions and should be read before relying on the online text.

In the United States the text of a statute is not copyrightable: it is an edict of government (*Georgia v. Public.Resource.Org*, 590 U.S. 255 (2020)). A register's copyright notice can still cover a publisher's annotations, headnotes and numbering, which this corpus does not reproduce.
