### Reading a result: FALSE and NOTHING (ccc27)

Every function here answers `MAYBE BOOLEAN` (or a `MAYBE` of a number, a date or a type).
`JUST TRUE` and `JUST FALSE` are answers the text gives; `NOTHING` is "this part does not decide it".
`JUST FALSE` never means "unlawful" or "not allowed" unless the function is named for a bar; read it with the function's name.
The questions in the seat layer read the same way: for a question named "may ...", JUST TRUE is yes, JUST FALSE is the text's own no, NOTHING is "the text does not answer on these facts".
A question named for a bar ("am I barred ...", "does the section bar ...") reads JUST TRUE as barred and JUST FALSE as the text's own "not barred".

The 170 `FALSE-kind` tags in layer 1 each quote the text that says no; the 180 `NOTHING-kind` tags each say why the text does not answer (limited by its own wording, undefined term, list not closed, silent, or points outside the section).
A number-valued function (a ceiling, a day, a count of days) can answer only NOTHING when its gate fails; it has no JUST FALSE (fork F-4).
