## Rules learned on the stable binary (this run; the longer list is NOTES.md, "What the stable binary does not accept")
- `NOT a AND b` is `NOT (a AND b)`: parenthesise every `NOT` (`(NOT a) AND b`).
- A strict srcrefs `@ref` below a declaration must cite lines inside the nearest quote run above it.
- `#ASSERT <deontic> EQUALS ...` is an Error: traces are read by eye, each regulative rule has a decision-function twin that is asserted.
- `IF/ELSE IF/ELSE` at one indent is a parse error with `THEN` on the same line as `ELSE IF`: use `BRANCH`.
- A `MAYBE BOOLEAN` input named like a function of the same module shadows it: inputs that carry another function's answer are named `the answer of s N ...`.
