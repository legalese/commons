## How the files are made (the pipeline lives in `../../../work/`, not shipped)
- Layer 1 and tests are authored as templates `work/src/<name>.l4`; `{{REF label | a-b}}` expands to the quote lines of raw lines a..b and `@ref label (src:a-b)`; `{{REFN ...}}` is the `@ref` alone (only where the nearest quote run above in the file covers it).
  `python3 -I work/expand.py` writes every template into `deposit/.../`; `work/t.sh <name>` expands, runs `l4 run` and prints the counts and the failing assertions (read from the diagnostics, not the exit code).
- The repealed module and its tests are generated from the coverage table by `work/gen_repealed.py`.
- The seat and its cases are generated by `python3 -I work/gen_seat.py` from `work/seat/*.spec` (a small spec language: `Q`, `was`, `in`, `ret`, `=`, `T`, with `M`/`E`/`D` macros; the header of `gen_seat.py` describes it); `work/seat/head.l4` and `cases-head.l4` hold the imports and the header comments. Expected values in the `T` lines were written from the text, with the reason after `//`.
- Coverage: `work/units.py` parses the text into rows; `work/mapping.txt` maps a row key (longest prefix wins) to a disposition; `python3 -I work/coverage.py` writes `work/coverage.md` and audits that every non-blank line is in exactly one row; `work/sanity.py` lists rows that inherit a non-encoded disposition from a parent (fork and inert-2 parents only, by design).
- `work/sigs.py` (function signatures of the layer-1 modules), `work/showsig.py`, `work/showbody.py`, `work/consts.py`, `work/names.py` are look-up helpers.
