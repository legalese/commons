# new-brunswick/

New Brunswick (Canada) legislation, one subject-id per body of law, following the subject-sidecar shape described in [`subjects/README.md`](../../README.md). The folder code is the lowercase ISO 3166-2 suffix, `nb` (CA-NB).

No subject is indexed here yet, and no text is deposited.

## Register access (2026-10-24)

**BLOCKED by a bot challenge.** New Brunswick's consolidated Acts and regulations are published by the Office of the Attorney General at laws.gnb.ca. On 2026-10-24 a request for https://laws.gnb.ca/robots.txt, with the honest user agent `legalese-commons-source-fetcher/1.0 (+https://github.com/legalese/commons)`, returned HTTP 403 with a Cloudflare "Just a moment..." JavaScript challenge. One request each to https://www2.gnb.ca/robots.txt and https://www.gnb.ca/0062/acts/acts-e.asp (the Government of New Brunswick's own hosts, which formerly carried the Acts) returned the same 403 challenge. Three requests in all, at least 3 s apart. A challenge is a refusal: no other client, user agent, proxy or mirror was tried, and unofficial aggregators (CanLII and the like) were not used.

The targets for tax and benefits, not reached: the **New Brunswick Income Tax Act** (personal income tax) and the **Family Income Security Act** with its General Regulation (income assistance rates). A human with access to laws.gnb.ca must index and source them, and read the site's own terms.

## Language

New Brunswick's Acts are enacted in English and French, and both versions are equally authoritative (Official Languages Act, SNB 2002, c O-0.5, and s 18 of the Canadian Charter of Rights and Freedoms).
