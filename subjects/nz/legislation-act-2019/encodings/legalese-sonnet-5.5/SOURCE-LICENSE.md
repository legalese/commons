# Source licence

The terms the quoted source text carries are recorded once, at subject level, in `../../SOURCE-LICENSE.md` of the run that deposited the text. This file points at that note and does not repeat it.

What this file adds:

- The text this encoding quotes (in the `-- src:N | ...` comment lines of the modules) is `../../registers/source-bundle/act_public_2019_58.txt`: **a plain-text rendering made by a converter script** (`workbench harvest/fetch-nz.py`) from the New Zealand Legislation website's text of the Legislation Act 2019 (2019 No 58). **It is not the official text.** It dropped subsection numbers and paragraph labels and flattened the tables.
- Nothing in this encoding has been verified against the official text, and none of it should be described as verified against the official text.
- The quotations were copied from that file by a script (`expand.py`); `srcrefs.py check` confirms each one against it.
- The licence of the encoding itself (the `.l4` files, the notes and the scripts) is Apache-2.0, as for the rest of canon; that is separate from the terms the source text carries.
