# Source license

The terms the quoted source text carries are written down once, at subject level, in `inputs/STUB-SOURCE-LICENSE.md` of this run (the licence note written when the text was deposited).
This file points at it and does not repeat it.

What this row quotes: the text of the Minors' Contracts Act 1987 (Singapore), 2020 Revised Edition, informal consolidation, version in force from 1 April 2022, as `-- src:N | text` lines copied by line number from `inputs/MCA1987.txt`.

`inputs/MCA1987.txt` is an unofficial plain-text rendering made by a converter script from Singapore Statutes Online (https://sso.agc.gov.sg/Act/MCA1987).
It is not the official text, and nothing in this row is "verified against the official text".
Readers should check Singapore Statutes Online for the latest version of the legislation.

The licence of the encoding itself (the `.l4` files, `NOTES.md`) is Apache-2.0, like the rest of the corpus it is deposited in.
