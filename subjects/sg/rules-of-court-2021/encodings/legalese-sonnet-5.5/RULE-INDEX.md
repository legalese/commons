# RULE-INDEX: every rule start in the text, by part (mechanical; line numbers are of the text file as it is)

Built by a script that finds each line beginning `N.` (a rule number) inside an Order, and takes the line above it as the rule heading.
A heading shown as `Division 2 -- ...` or a sub-heading means the heading regex took the wrong line; the rule number and line are still right.
A rule number missing from a run (for example O 4 r 5) is absent from this consolidation: the text shows no heading or body for it.
Use it to build the coverage table: one row per line below, plus a row for each Order heading and each Division heading.
