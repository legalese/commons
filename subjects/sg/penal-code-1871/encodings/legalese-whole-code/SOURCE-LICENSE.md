The licence, the required attribution and the other conditions for the source text are the subject's, and are in the subject's source licence note: `../../SOURCE-LICENSE.md`.
This file points at it and does not repeat it.

**What this row adds to it.** The source is the subject's `registers/source-bundle/PC1871.txt`, a converter's plain-text rendering of the Singapore Statutes Online print of the Code ("Current version as at 09 Sep 2026"; sha256 `066301837e6413cf635bf0dc21a44186705b9d892b04a2cdd1036afbd9e269f2`), which is an unofficial consolidation, not the official text.
The modules quote the Code's text in comments beside the rules: since version 0.2.0 every quotation is a `-- src:N | text` line copied from that file by script and checked by `srcrefs.py` (1,400 such lines in the four modules added in 0.2.0).
How much of the Code appears verbatim across the 31 encoding modules has not been measured; for the encoded sections, expect most of it.
