## Method (how a module gets written)

1. Write `scratch/src/<module>.in.l4` with `--@Q A-B,C | citation` macros before each rule.
2. `python3 -I qx.py <in> <out>` (BA text) or `python3 -I qx.py --raw BA1994-<ID> <in> <out>` (an instrument deposit) expands each macro into `-- src:N | text` lines plus `@ref citation (src:lo-hi)`.
3. `l4 check` the output, then edit the OUTPUT file by hand from then on (the .in files go stale).
4. Pitfalls found: a leading `(a OR b)` line followed by `AND` lines at the same column warns "AND and OR at same indentation": put `AND (x OR y)` as a line that begins with AND, or one line; a one-line nested CONSIDER with several WHEN does not parse (use EQUALS); a `@ref` at end of file warns; two `GIVEN` lines in a row do not parse; `sed -i` on macOS needs `''`.
5. `gen-coverage.py rows TEXT` lists 839 rows; `gen-coverage.py table TEXT dispositions.tsv` makes the table (dispositions.tsv not yet written).
