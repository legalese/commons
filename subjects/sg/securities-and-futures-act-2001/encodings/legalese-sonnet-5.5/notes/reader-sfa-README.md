# Independent readers of Cut A

Four reader groups wrote their own answers to scenarios taken from the text of the ranges this folder encodes, then ran them against the encoding: group 1 the keel's Part 1 (lines 1668 to 4224) and `sfad`, group 2 `sfaa`, group 3 `sfab`, group 4 `sfac`.
Each group's triage file is `reader-sfa-g<n>-triage.md` in this folder, as the group wrote it, with local names and paths replaced by placeholders. `../NOTES.md`, section "Independent readers of Cut A", has the counts and every `ENCODER`, `AMBIGUOUS` and `GAP` line.

**Not shipped:** each group's `ANSWERS.md` (the scenarios and the answers written from the text), its `tests-independent.l4`, its prompt and its working files. A line number in a triage file therefore points at a file you do not have; the provision, the text line and the two answers in each line are enough to rerun the scenario by hand.
The lead reran each group's test file on the stable build (1.6.110) and got the same counts as the group.
