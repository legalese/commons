## How the files are made (important after a compaction)

- Templates live in scratchpad `crtpa-src/` (NOT in the deposit): `crtpa-*.l4` with `{{src N M}}` markers.
  `python3 crtpa-src/build.py` expands each marker with `srcrefs.py quote` (never retype a quotation) and writes the deposit.
  EDIT THE TEMPLATES, then run build.py; a hand edit in the deposit is overwritten by the next build.
- `crtpa-src/qrun.sh FILE` runs a deposit file on main-109 and prints errors/warnings/satisfied; `crtpa-src/chk.sh FILE` type-checks and runs srcrefs --refs.
- `crtpa-seat.l4` is generated by `crtpa-src/gen-seat.py` (inputs declared once, questions list keys); `crtpa-cases-seat.l4` by `crtpa-src/gen-cases.py` (expected values hand-written in the script, reason beside each).
  EDIT THE GENERATORS, run `python3 gen-seat.py && python3 gen-cases.py && python3 build.py` from crtpa-src.
- scratchpad = <scratch>
- Never put backticks inside an unquoted shell heredoc (the shell runs them as commands); use the Write tool or a quoted heredoc ('EOF').
