# Source licence: the text quoted by this encoding

The terms the quoted text of Magna Carta (1297), 1297 c. 9 (25 Edw. 1), carries are recorded in `../../SOURCE-LICENSE.md`, the subject-level note written when the text was deposited.
This file points at it and does not repeat it.
The four points that note lists as not checked stay open here: a notice specific to this document, the site's re-use page, the text of the Open Government Licence v3.0 itself, and whether the site's editorial layer is "otherwise stated".

What this encoding quotes, so that the question is real:

- The `-- src:` comment lines in the `mc97-*.l4` modules quote the source text verbatim (75 lines on 2026-10-29), each checked by `srcrefs.py` against the extract.
- `mc97-status.l4` holds 34 strings generated from `status-entries.tsv`, which is the extract author's extraction of the site's repeal annotations, with three abbreviations expanded.
- `NOTES.md` quotes short passages of the text between curly double quotes; `gen-coverage.py` checks each against the extract.

The quoted text is the site's traditional translation as another session transcribed it from the rendered XML.
It is not the official text, the transcription is not byte-exact, and nothing here is verified against the official text.

Attribution wording, as `../../SOURCE-LICENSE.md` gives it (the note says the wording is borrowed from a sibling deposit and was not re-read here):
Contains public sector information licensed under the Open Government Licence v3.0.

This file says nothing about the licence of the encoding itself, which is Apache-2.0 like the rest of canon.
