## Method (so a resumed session can continue)
- Source for each module is `src/<module>.l4.in` in the scratch folder `runs/iaw-ssc2/work/` (outside the deposit; not shipped), with markers `%%QR label | a-b` (quote raw lines + @ref), `%%R label | a-b` (@ref only), `%%Q a-b`. Build: `cd runs/iaw-ssc2/work && python3 -I build.py <module>.l4.in` writes the `.l4` beside check.sh. NEVER edit the generated `.l4` directly; edit the `.l4.in`.
- Strict srcrefs rule learned: an `@ref` with no quote run above it in its own block is checked against the NEAREST run above in the file, so use `%%QR` (quote again) unless the run is directly above.
- Test files are written by hand directly in the deposit folder (`ssc2-tests-*.l4`).
- `work/r.sh FILE.l4` runs one file and prints counts and errors. `check.sh` is run as in the brief.
- Coverage: `work/units.py` (units from the raw text -> units.json), `disp.py` (dispositions by unit-id prefix; `key*` = descendants only), `coverage.py [table]` joins them and checks every L4 name cited exists. Notes pieces are in `work/notes/*.md` (forks, marginal, seams, findings); NOTES.md is assembled from them at the end.
- L4 gotchas found: a genitive after a function application needs brackets (`f (r's x)`); `NOT EQUALS` does not exist (`NOT (a EQUALS b)`); `MAYBE (LIST OF X)` needs the brackets; `count` is the list length; the core type is `Tax year` in backticks; `#TRACE` needs a `WITH` (use `#EVAL` for a rule with no events); bare rows of dots cannot be quoted (build.py skips them and narrows the locator).
