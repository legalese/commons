## Method
1. Layer-1 modules are GENERATED from ENC/tools/templates/*.l4.in by `python3 -I tools/build.py [name ...]`; `{{Q ids}}` expands to verbatim `-- src:N | clause` lines read from RAW and `{{REF n [extra]}}` to the `@ref`.
   Edit the template, never the generated .l4.
2. `tools/units.py` (+ `tools/splits.json`) segments RAW into 231 units.
3. `tools/dev.sh mod ...` builds named templates and prints only errors/warnings; `tools/t.sh mc15-tests-x` runs a hand-written test file and counts asserts.
4. Test files `mc15-tests-*.l4` were written from the text before they were run.
   A DEONTIC cannot be asserted on the stable build: every regulative rule is gated by a decision function that carries the asserts, and `#TRACE`s carry a `-- expect:` line checked by `check-traces.py`.
5. Seat = `mc15-seat.l4` + `mc15-cases-seat.l4`, generated by `python3 -I tools/seatgen.py` from the table in `tools/seatspec.py`.
6. The rule for a source that does not answer (team lead's refinement): a "no" value (`Not barred`, `Not entitled`, `Not obliged`) only where the text says no in its own words.
   Every such branch has a `-- FALSE-kind` comment quoting the words; every "not covered" branch has a `-- NOTHING-kind (<why>)` comment.
   `python3 -I tools/branchcheck.py > tools/branch-output.txt` checks both, checks that every quotation in a `-- FALSE-kind` comment is in the function's `-- src:` lines, and checks that a "not covered" branch in a function whose source holds if, unless, while, until, except and the like is either a no or carries `-- NOTHING-kind (word not the condition here: ...)`; it must exit 0; `python3 -I tools/failing.py <l4> <file>` lists failed assertions with their lines.
   The readings behind it are F64a to F64e in the fork register.
   A second pass (2026-10-30, from the team lead's fix list) changed 23 branches to the text's no and swept the rest; `python3 -I tools/sweeptable.py > tools/sweep-output.txt` lists them (NOTES.md, "The sweep of the not-covered branches").
7. NOTES.md is generated: edit `tools/NOTES.md.in`, `tools/forks.py`, `tools/jural.py`, then `python3 -I tools/coverage.py` (it also writes coverage-map.tsv).
   The pasted check outputs are `tools/check-output.txt`, `tools/trace-output.txt`, `tools/srcrefs-output.txt`, `tools/branch-output.txt`, `tools/sweep-output.txt`; regenerate them (see NOTES.md) before coverage.py if any module changes.
