## How the files are made (IMPORTANT, survives compaction)
Source of truth for each layer-1 .l4 is a TEMPLATE in inputs/scratch-probes/tpl/<name>.l4.tpl.
`python3 inputs/scratch-probes/expand.py <name>.l4.tpl` replaces each line `@@Q N M` with the verbatim `-- src:N | text` lines from srcrefs.py quote and writes deposit/.../<name>.l4.
Edit the .tpl, then expand. Never hand-edit the generated .l4 (the quote lines are machine-copied, which is the point).
inputs/scratch-probes/diag.sh FILE.l4 prints one line per diagnostic (empty = clean).

## Lessons from the stable binary (for NOTES.md "What the stable binary does not accept")
- a left-nested chain of ten PLUS took 27 s to type-check; `sum (LIST a, b, ...)` takes 0.5 s. Chains of 3 are fine.
- `...` (AND-sugar) at the start of a line next to `OR` at the same column triggers the AND/OR same-indentation lint warning; put `"label" ... atom` on ONE line and join rungs with OR / AND / `..`.
- srcrefs R3: a quote run followed by a declaration needs an @ref locator that overlaps it; a run immediately before a `§§` heading is exempt, so put `-- (not encoded: ...)` notes at the end of a section block.
- genitive in a function argument needs parentheses: `filter f (x's y)`.
- list of records literal: `LIST (R WITH a IS 1, b IS 2), (R WITH a IS 3, b IS 4)`.
- `Date n` (one number) turns a day count back into a date; `Day d` is the day count.
